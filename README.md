# IPL Auction Arena 🏏

A polished multiplayer IPL auction game for friends.

## Features
- Room-based multiplayer using PeerJS (no central game server required for the prototype)
- Host-controlled nominations, bidding timer, sold/unsold flow
- Eight IPL franchises with ₹100 Cr budgets
- Search/filterable player pool
- Current-player and IPL-legend/retired-player pools
- Live auction activity and chat
- Responsive desktop/mobile UI

## Run
Open `index.html` in a browser or deploy the repository as a static site. For multiplayer, the browsers need internet access to reach the PeerJS signaling service.

## Important data note
The player pool is a curated game dataset containing current players and notable former IPL players. It is not an official, exhaustive retirement register; player status and franchise labels should be reviewed before using it for a formal/statistical application.
